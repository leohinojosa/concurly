# Theme System Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace concurly's hard-coded look with a token-driven theme system: the Paper/Midnight single-bar layout, seven themes, a header theme picker (right of ↻), and a choice that persists in `localStorage` and `~/.concurly/preferences.json`.

**Architecture:** Themes are data in `src/themes.json` (54 tokens each, verified for WCAG AA), injected into `client.js` by `cli.ts` via a `"__THEMES__"` placeholder. `client.js` emits one `html[data-dr-theme="…"]` CSS-variable block per theme plus a single token-driven stylesheet; two archetype attributes (`data-dr-tabs`, `data-dr-cards`) switch structural CSS. A small theme engine applies/persists the choice; the server gains `GET/PUT /preferences` backed by `src/prefs.ts`.

**Tech Stack:** TypeScript → CommonJS, Express 4, vanilla-JS `client.js` (no imports), `node:test`, headless Edge + CDP (via the existing `ws` dependency) for browser verification.

**Spec:** `docs/superpowers/specs/2026-11-05-themes-design.md`
**Verified theme data (companion file):** `docs/superpowers/plans/2026-11-05-themes.data.json` — contrast-checked; Task 1 copies it to `src/themes.json`.

**Conventions**
- Work in the `themes` worktree; run every command from its root.
- Commit messages end with the trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- `npm test` = build + `node --test test/`.
- `client.js` stays plain JS (no TypeScript syntax, imports or `require()`); all injected DOM keeps the `__dr-` prefix; **no hard-coded colors** — only `var(--dr-*)`.
- Never write or print a URL containing `?token=` (unchanged rule).

function parse(c) {
  c = c.trim().toLowerCase();
  if (c === "transparent") return [0, 0, 0, 0];
  let m = c.match(/^#([0-9a-f]{6})$/);
  if (m) return [0, 2, 4].map((i) => parseInt(m[1].slice(i, i + 2), 16)).concat(1);
  m = c.match(/^rgba?\(([^)]+)\)$/);
  if (m) { const p = m[1].split(",").map(Number); return [p[0], p[1], p[2], p.length > 3 ? p[3] : 1]; }
  throw new Error("unparseable colour: " + c);

function over(fg, bg) {
  return [0, 1, 2].map((i) => Math.round(fg[i] * fg[3] + bg[i] * (1 - fg[3]))).concat(1);

```ts
import fs from "fs";
import path from "path";
import { concurlyHome } from "./paths";

/** User preferences shared across all concurly sessions/ports. Extend by adding optional fields. */
export interface Preferences {
  theme?: string;
}

const THEME_ID = /^[a-z0-9-]{1,32}$/;

export function isValidTheme(value: unknown): value is string {
  return typeof value === "string" && THEME_ID.test(value);
}

export function prefsPath(): string {
  return path.join(concurlyHome(), "preferences.json");
}

/** Keeps only known, valid fields. */
export function sanitize(input: unknown): Preferences {
  const out: Preferences = {};
  if (input && typeof input === "object") {
    const theme = (input as Record<string, unknown>).theme;
    if (isValidTheme(theme)) out.theme = theme;
  }
  return out;
}

export function readPrefs(): Preferences {
  try {
    return sanitize(JSON.parse(fs.readFileSync(prefsPath(), "utf-8")));
  } catch {
    return {};
  }
}

/** Merges `patch` into the stored preferences (atomic temp + rename) and returns the result. */
export function writePrefs(patch: unknown): Preferences {
  const next: Preferences = { ...readPrefs(), ...sanitize(patch) };
  const file = prefsPath();
  fs.mkdirSync(path.dirname(file), { recursive: true });
  const tmp = `${file}.tmp`;
  fs.writeFileSync(tmp, JSON.stringify(next, null, 2), "utf-8");
  fs.renameSync(tmp, file);
  return next;
}
```

Insert this block directly above `// ─── Selector builder` (it only needs `THEME_DATA` and `PORT`):

```js
  // ─── Themes ───────────────────────────────────────────────────────────────
  const THEME_KEY = "concurly-theme";
  const THEMES_BY_ID = Object.fromEntries(THEME_DATA.themes.map((t) => [t.id, t]));
  let savedTheme = null; // the user's explicit choice (persisted), or null → follow the OS

  function isThemeId(id) {
    return typeof id === "string" && Object.prototype.hasOwnProperty.call(THEMES_BY_ID, id);
  }
  function osTheme() {
    const dark = window.matchMedia && window.matchMedia("(prefers-color-scheme: dark)").matches;
    return dark ? THEME_DATA.default.dark : THEME_DATA.default.light;
  }
  function effectiveTheme() {
    return savedTheme || osTheme();
  }
  function readStoredTheme() {
    try {
      const v = localStorage.getItem(THEME_KEY);
      return isThemeId(v) ? v : null;
    } catch {
      return null;
    }
  }
  function storeTheme(id) {
    try { localStorage.setItem(THEME_KEY, id); } catch { /* private mode etc. */ }
  }
  function putThemePreference(id) {
    fetch(`http://localhost:${PORT}/preferences`, {
      method: "PUT",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ theme: id }),
    }).catch(() => {});
  }

  /** Applies a theme to the page (no persistence). Safe to call for previews. */
  function showTheme(id) {
    const t = THEMES_BY_ID[id];
    if (!t) return;
    const root = document.documentElement;
    root.setAttribute("data-dr-theme", t.id);
    root.setAttribute("data-dr-tabs", t.tabs);
    root.setAttribute("data-dr-cards", t.cards);
  }

  /** The user committed a choice: apply it and persist it (localStorage + server). */
  function chooseTheme(id) {
    if (!isThemeId(id)) return;
    savedTheme = id;
    showTheme(id);
    storeTheme(id);
    putThemePreference(id);
  }

  async function syncThemeFromServer() {
    try {
      const res = await fetch(`http://localhost:${PORT}/preferences`, { cache: "no-store" });
      if (!res.ok) return;
      const prefs = await res.json();
      if (isThemeId(prefs.theme)) {
        if (prefs.theme !== savedTheme) {
          savedTheme = prefs.theme;
          storeTheme(prefs.theme);
          showTheme(prefs.theme);
        }
      } else if (savedTheme) {
        putThemePreference(savedTheme); // server has none yet: seed it from this browser
      }
    } catch { /* server unreachable: localStorage / OS default still apply */ }
  }

  function initTheme() {
    savedTheme = readStoredTheme();
    showTheme(effectiveTheme());
    if (window.matchMedia) {
      const mq = window.matchMedia("(prefers-color-scheme: dark)");
      const onChange = () => { if (!savedTheme) showTheme(osTheme()); };
      if (mq.addEventListener) mq.addEventListener("change", onChange);
      else if (mq.addListener) mq.addListener(onChange);
    }
    syncThemeFromServer();
  }
```

      const group = document.createElement("div");
      group.className = "__dr-theme-group__";
      group.textContent = title;
      menu.appendChild(group);

      THEME_DATA.themes.filter((t) => t.mode === mode).forEach((t) => {
        const item = document.createElement("button");
        item.className = "__dr-theme-item__";
        item.dataset.theme = t.id;
        item.setAttribute("role", "menuitemradio");
        item.setAttribute("aria-checked", String(t.id === current));

        const swatch = document.createElement("span");
        swatch.className = "__dr-swatch__";
        [t.vars.bg, t.vars.accent, t.vars.fg].forEach((color) => {
          const chip = document.createElement("i");
          chip.style.background = color;
          swatch.appendChild(chip);
        });

        const name = document.createElement("span");
        name.textContent = t.label;

        const check = document.createElement("span");
        check.className = "__dr-theme-check__";
        check.textContent = "✓";

        item.appendChild(swatch);
        item.appendChild(name);
        item.appendChild(check);

        item.addEventListener("mouseenter", () => showTheme(t.id)); // live preview
        item.addEventListener("focus", () => showTheme(t.id));
        item.addEventListener("click", () => {
          chooseTheme(t.id);
          closeThemeMenu(true);
        });
        menu.appendChild(item);
      });
    });

    const r = btn.getBoundingClientRect();
    menu.style.right = `${Math.max(8, window.innerWidth - r.right)}px`;
    document.body.appendChild(menu);
    themeMenu = menu;
    btn.setAttribute("aria-expanded", "true");

    const items = themeItems();
    (items.find((i) => i.dataset.theme === current) || items[0]).focus({ preventScroll: true });
  }

  function buildThemeButton() {
    const btn = document.createElement("button");
    btn.id = "__dr-theme-btn__";
    btn.title = "Theme";
    btn.setAttribute("aria-label", "Theme");
    btn.setAttribute("aria-haspopup", "menu");
    btn.setAttribute("aria-expanded", "false");
    btn.innerHTML = PALETTE_SVG;
    btn.addEventListener("click", (e) => {
      e.stopPropagation();
      if (themeMenu) closeThemeMenu(false);
      else openThemeMenu();
    });
    return btn;
  }

  // Keyboard inside the open menu.
  document.addEventListener("keydown", (e) => {
    if (!themeMenu) return;
    const items = themeItems();
    const i = items.indexOf(document.activeElement);
    if (e.key === "ArrowDown") { e.preventDefault(); items[(i + 1) % items.length].focus(); }
    else if (e.key === "ArrowUp") { e.preventDefault(); items[(i - 1 + items.length) % items.length].focus(); }
    else if (e.key === "Home") { e.preventDefault(); items[0].focus(); }
    else if (e.key === "End") { e.preventDefault(); items[items.length - 1].focus(); }
    else if (e.key === "Escape") { e.preventDefault(); e.stopPropagation(); closeThemeMenu(true); }
    else if (e.key === "Tab") { closeThemeMenu(false); }
  }, true);

  // A click outside only closes the menu; swallow it so it can't also place a comment box.
  document.addEventListener("click", (e) => {
    if (!themeMenu) return;
    if (e.target.closest("#__dr-theme-menu__") || e.target.closest("#__dr-theme-btn__")) return;
    e.preventDefault();
    e.stopPropagation();
    closeThemeMenu(false);
  }, true);

  window.addEventListener("resize", () => closeThemeMenu(false));

## Appendix B — browser verification helper (`scripts/theme-check.js`)

A throwaway developer script (not part of the shipped package; add `scripts/` to the commit only if wanted). It starts a real concurly session against a temp `CONCURLY_HOME`, launches headless Edge with remote debugging, and drives it over the Chrome DevTools Protocol using the repo's existing `ws` dependency.

Commands: `shots [ids…]` (screenshot each theme in review state and on the history tab, theme set through `PUT /preferences`) and `picker` (the seven-point assertion list in Task 5, Step 4). It must:

1. Create a temp `CONCURLY_HOME`; write a small sample `design.html` and a `design.comments.json` with two open comments and one resolved one.
2. `spawn node dist/cli.js open <file>` with `CONCURLY_HOME` and `CONCURLY_NO_BROWSER=1`; parse the port from `running on http://localhost:<port>`.
3. Launch `msedge.exe --headless=new --remote-debugging-port=<p> --user-data-dir=<tmp> --window-size=1300,760 about:blank`, poll `http://127.0.0.1:<p>/json` for the page target, and connect to its `webSocketDebuggerUrl`.
4. Provide `send(method, params)`, `navigate(url)` (`Page.navigate` + wait for `Page.loadEventFired`), `evaluate(expr)` (`Runtime.evaluate`, `returnByValue`), `click(selector)` (evaluate `el.click()`), `key(name)` (`Input.dispatchKeyEvent` down/up), `hover(selector)` (evaluate `el.dispatchEvent(new MouseEvent("mouseenter"))`), `screenshot(path)` (`Page.captureScreenshot` → base64 file), and `emulateScheme("dark"|"light")` (`Emulation.setEmulatedMedia` with `prefers-color-scheme`).
5. Always shut down Edge and the concurly session (`node dist/cli.js complete <port>`) in a `finally`, and delete the temp folder.
6. Use `assert` for the `picker` checks; print one line per check and exit non-zero on the first failure.
